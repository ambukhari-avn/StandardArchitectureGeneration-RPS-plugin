# v1.7.2 implementation plan — architecture generation engine

Goal: move correctness from instructions into the engine. Every rule below is enforced in code; the instruction text is shortened to
one hierarchy that points at the commands, so the AI has nothing contradictory to choose between.

## 2. Instruction hierarchy (highest first) — enforced, not just stated

1. **Locked template**: footer, logo, scope colours, cable legend/colours, fixed artwork, A3 editable Visio (`qa.check_template`, fixed-picture hashes).
2. **User-confirmed specification**: quantities, units, topology, connections, placement constraints (`verify-diagram`, blocking).
3. **Mandatory engineering rules**: no invented equipment/links/redundancy; hardwired to actual I/O (`validate`, `qa`).
4. **Engine layout**: functional rows, minimum sizes, corridors, routing (`reference_layout`, `router`, `separate`).
5. **Presentation refinements**: pictures, waypoints, width weights (kept across revisions with `--previous`).

A lower level may never override a higher one; the code checks it.

## 4. Schema changes (diagram.json; all optional, backwards compatible)

- shape `category` (e.g. `plc`, `io`, `instrument`), `tag` (ISA letters for the balloon fallback).
- shape `place`: `{"left_of": id}` / `right_of` / `above` / `below` (same container) — relative constraints.
- group `bus`: `{"id", "cable", "label", "row", "side": "below"|"above"}` — a common graphical network bus for the members of one row; lines may end on the bus id.
- line `waypoints`: `[[x, y], ...]` page inches — locked route points.
- top-level `logical_links`: `[{"id": "CN-001", "units": [["EQ-004-1", "EQ-006-1"], ...], "cable": "ethernet"}]` — what must be connected, whatever the drawing shows.
- spec connection `display`: `auto | point-to-point | bus | cross | chain | ring | consolidated`; spec `layout.place` constraints.
- build CLI: `--preview` writes `<out>.layout.json`; `--locked-layout <file>` verifies before export.

## 5. Acceptance criteria (release gate)

1. All existing tests (221) and new regression tests pass.
2. Every sample and example builds with zero QA defects; any defect blocks the build after automatic correction.
3. `verify-diagram` refuses a diagram with a missing unit, a changed quantity, a missing logical connection or a violated constraint.
4. Preview and export geometry are identical; export with a stale lock is refused.
5. PLC and remote I/O pictures meet their minimum displayed sizes in examples A–D; instruments never show the generic device icon.
6. A revision with `--previous` keeps unchanged shapes' pictures and waypoints; only affected equipment/connections change.
7. Buses, point-to-point, cross-connections, chains, rings and consolidated hardwired all build and pass QA in tests.
8. Footer, logo, scope colours, cable legend, fixed artwork unchanged (template lock and fixed-picture hashes); output stays editable A3 Visio.
9. Previews of A–D inspected by eye before release; version 1.7.2 shown everywhere.
